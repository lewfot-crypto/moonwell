# 달우물 괴담회

모바일 픽셀 괴담 웹앱. 설치나 빌드 없이 GitHub Pages로 실행합니다.

## 배포
1. ZIP을 풀고 안의 파일들을 저장소의 최상위에 업로드합니다. 폴더째 넣지 않습니다.
2. Settings → Pages → Deploy from a branch → main → / (root) → Save.
3. Pages에 표시된 실제 배포 주소를 Safari로 엽니다.
4. Safari 공유 → 홈 화면에 추가 → 웹 앱으로 열기 → 추가.

## 포함 기능
시작 화면, 다섯 요괴와 촛불, 괴담 세 편, 오늘의 운세, 타로 한 장, 기록첩, 설정.
자유 입력은 준비된 반응이며 AI 연결은 없습니다. 기록은 기기 브라우저에 저장됩니다. 오프라인 설치 기능은 포함하지 않습니다.
