# 달우물 괴담회 v0.17

index.html, assets 폴더, 아이콘과 manifest.webmanifest를 저장소의 최상위에 올립니다.
Settings → Pages → Deploy from a branch → main / (root) → Save.
주소: https://lewfot-crypto.github.io/moonwell/

아이폰에서는 위 주소를 사파리로 열고 공유 → 홈 화면에 추가를 선택합니다.
ChatGPT 또는 파일 앱의 HTML 미리보기는 실행이 제한될 수 있습니다.
모든 그림과 글꼴은 포함되어 있으며 음악은 브라우저에서 자체 생성됩니다.


작업과 배포 지침은 PROJECT_GUIDE.md, 다음 개발자가 지킬 사항은 AGENTS.md를 참고하세요. icon-drafts에는 아이콘 후보 두 개가 있으며 최종 선택 후 설치 아이콘에 적용합니다.
